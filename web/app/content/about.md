## 你好，我是 Fishmo

欢迎来到我的个人博客。这里记录技术、生活，以及一些还没想清楚、但值得留下来的东西。

## 关于这个博客

这个博客由 **Nuxt 4 + Tailwind CSS 4** 驱动前台，后台是 **FastAPI + SQLAlchemy 2.0（异步）+ MySQL + Redis**。整体采用玻璃拟态风格：固定的背景图、半透明卡片与轻微模糊，希望阅读时安静一点，也轻盈一点。

文章、封面与正文图片由管理端维护；评论需要登录后才能发表，登录状态只保存在你自己的浏览器里。

## 技术栈

- **后端：** Python 3.12、FastAPI、SQLAlchemy 2.0（异步）、MySQL、Redis
- **前端：** Nuxt 4、Vue 3、TypeScript、Tailwind CSS 4
- **其他：** Cloudinary（图片）、Resend（邮件）、Git、Docker、Linux
